# Release Documentation

This directory documents release policy, versioning, asset naming, and verification.

Recommended release asset naming:

```text
grace-l2-pipeline-vX.Y.Z-win-x64-setup.exe
grace-l2-pipeline-vX.Y.Z-win-x64-portable.zip
grace-l2-pipeline-vX.Y.Z-linux-x86_64-cli.tar.gz
grace_l2_pipeline-X.Y.Z-py3-none-any.whl
grace_l2_pipeline-X.Y.Z.tar.gz
checksums.txt
```

A release should document:

- supported platforms;
- Python and MATLAB requirements;
- included and excluded data;
- changed workflow behavior;
- known issues;
- validation cases;
- checksums.
