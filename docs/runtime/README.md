# Runtime Guides

This directory groups runtime-specific documentation.

Planned documents:

- `windows-python.md`: Python GUI, CLI, and Windows packaging.
- `windows-matlab.md`: MATLAB local execution on Windows.
- `linux-python.md`: Python CLI execution on Linux.
- `linux-matlab.md`: MATLAB batch execution on Linux.
- `hpc.md`: Windows-to-HPC submission and SLURM operation.

During the staged migration, legacy commands remain valid. New documentation should prefer:

```text
configs/
src/python/
src/matlab/
packaging/
outputs/
```
