# Data Documentation

This directory documents input data, output conventions, and metadata.

Planned documents:

- `input-data.md`: GRACE/GRACE-FO Level-2, low-degree coefficients, DDK kernels, basin boundaries, GLDAS, CSR Mascon, and Hydroweb inputs.
- `output-convention.md`: grid dimensions, file naming, units, and output metadata.
- `metadata.md`: required metadata fields for reproducibility.

Large input datasets must remain under `data/` and should not be committed.
