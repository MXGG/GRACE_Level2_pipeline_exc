# Metrics Module

## Responsibility

**English**

`matlab/src/metrics/` compares products against reference data and accumulates monthly and stack-level evaluation metrics.

**中文**

`matlab/src/metrics/` 用于将处理结果与参考数据进行对比，并累计逐月和整段 stack 级别的评估指标。

## Scope

**English**

This module should focus on evaluation logic, reference alignment, and metric summaries. It should not become a second copy of the main pipeline orchestration.

**中文**

本模块应聚焦于评估逻辑、参考数据对齐和指标汇总，不应演变成主流水线编排逻辑的第二份副本。
