# Examples

This directory is reserved for small, reproducible examples.

Recommended examples:

```text
examples/
├─ quickstart-python/
├─ quickstart-matlab/
├─ caspian-leakage/
└─ basin-timeseries/
```

Do not place large GRACE, GLDAS, Mascon, Hydroweb, or basin boundary datasets here. Use small synthetic or reduced sample files only.
